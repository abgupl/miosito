# Sito BESTPRICE24H

Questa cartella contiene una versione semplice e modificabile del sito offerte.

- `index.html`: testi e struttura della pagina.
- `style.css`: colori, dimensioni, margini e grafica.
- `app.js`: caricamento automatico delle offerte da Railway, ricerca e filtri.

Le offerte vengono lette da:

`https://miosito-production.up.railway.app/api/offerte`

Modificare questi file su GitHub non aggiorna automaticamente il sito pubblicato su ChatGPT Sites. Dopo una modifica bisogna pubblicare la nuova versione oppure chiedere a Codex di sincronizzarla.
